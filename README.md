# Разработка демонстрационного VR-приложения «Взаимодействие с виртуальной реальностью через трекинг частей тела пользователя»

Демонстрационное VR-приложение-песочница, реализующее базовые и продвинутые механики взаимодействия без контроллеров.

## Статус проекта (после предзащиты)

### ✅ Уже реализовано

**Базовые механики (CoreMechanicsScene):**
- Захват и бросание объектов одной рукой (щипок)
- Двуручный захват (одновременное удержание объекта двумя руками)
- Физика предметов (масса, трение, сила броска)
- Стол с интерактивными объектами (куб, сфера, цилиндр)


**UI и навигация (HubScene, UIScene):**
- Системное меню с кнопками для переключения между сценами (аддитивная загрузка)
- Указание на расстоянии (луч подсвечивает объекты)
- Переходы между сценами без потери XR Origin

**Отладка (DebugScene):**
- Базовый вывод информации о трекинге рук (в процессе наполнения)

**Продвинутые механики (PrecisionToolsScene):**
- Штангенциркуль (функционал) (PrecisionToolsScene) 
- Микрометр (функционал) (PrecisionToolsScene)
- Продвинутые кейсы (AdvancedScene)
- работа с планшетом/блокнотом
- химические/лабораторные процедуры

**Инфраструктура:**
- Проект работает на Unity 6.4 с OpenXR и XR Interaction Toolkit 3.4.1
- Поддержка VR-очков (тестировалось на реальном устройстве)
- Репозиторий GitHub настроен для командной работы
- Аддитивная загрузка сцен через Bootstrapper

## Установка и запуск

1. Установите **Unity 6.4(6000.4.1f1).
2. Склонируйте репозиторий:  
   `git clone https://github.com/ваш-аккаунт/vr-sanbox-project1.git`
3. Откройте проект в Unity.
4. Убедитесь, что установлены пакеты (через Package Manager):
   - XR Interaction Toolkit (3.x)
   - OpenXR Plugin
   - XR Device Simulator
5. Откройте сцену `Assets/Scenes/Bootstrapper.unity`.
6. Нажмите **Play**.

## Структура проекта (основные папки)

- `Assets/Scenes/` – главная сцена `MainScene`
- `Assets/Scripts/Input/` – абстракция ввода (`IHandInput`, `MouseHandInput`)
- `Assets/Scripts/Interaction/` – захват, бросание
- `Assets/Scripts/Locomotion/` – телепортация, движение
- `Assets/Scripts/UI/` – системное меню, указание
- `Docs/` – таблица жестов, баг-трекер, отчёты
